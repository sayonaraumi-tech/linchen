# 月輪合同会社｜9ページ UI デザイン案 B

## 範囲

PC向け9ページを、既存CSSの上書きではなく単一の新規画面実装として構成しました。

1. ホーム
2. 日程
3. 見積履歴
4. 帳票
5. 保存帳票
6. 売上・入金
7. 支出・現金
8. 銀行照合
9. 設定

## 確認方法

`index.html` をブラウザで開きます。左側ナビで9画面を切り替えられます。銀行明細の行選択、日程の日付移動、帳票の種類切替、明細行追加・削除、見積検索などは画面上で動作します。

## 重要な制限

- **UIのデモのみ。** 取引や金額はサンプルで、既存業務データではありません。
- このリポジトリのmainブランチのルートには既存ファイルが見つからなかったため、重複CSSや上書き構造があるという証拠はありませんでした。既存コードを削除したわけではありません。
- 銀行CSV取込、銀行照合の確定、Firestore更新、売上の確定、帳票保存、正式PDF発行は**未実装**。画面のボタンは実データを書き換えません。
- 帳票プレビューは**概略表示**です。実物の見積書・請求書・領収書・小野田の正式PDFテンプレートがこのリポジトリにないため、PDF一致は未検証です。正式テンプレートを取得してからプレビューへ接続してください。
- 年度は10月1日〜翌年9月30日。画面の表示例は2026年度です。
- 独立した開発ブランチでのみ作成し、mainは未変更です。

## デザイン基本原則

- サイドバー：#171717、アクセント：#B99755、ページ背景：#F5F5F3。
- 白い明細画面、薄い区切り線、コンパクトな表。
- 銀行照合は、銀行明細 → 選択明細 → 照合候補・処理という同一画面の流れ。
- 業務ロジックと表示を分離し、見た目のためだけの特例判定を追加しない。
- 将来の実装ではPDF原本・履歴データ・銀行照合・現金帳の既存ルールを保全する。
