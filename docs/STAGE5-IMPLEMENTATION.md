### 安全约束

1. PDF 源码复制通过，不表示新业务模块已经完成 PDF 集成。
2. 帳票正式发行和数据变动分离：保存时创建或复用 sale/payment，重下载不得触发 `issueDocument`。
3. 已确认现金收款始终对应一条 sale、一条 payment、一条 cashLedger；操作 ID 保证幂等。
4. 银行明细导入通过账户和 externalId 防重复，银行照合复用已存在的 pending payment 或 expense；不产生第二笔売上。
5. 被确认银行记录引用的付款和支出，不允许绕过解除匹配直接删除。
6. 测试记录「削除」需显式操作和确认；有活跃关联的记录应先通过专用操作解除。
7. 金额暂按整数日元存储，真实消费税拆分、不同税率和历史税额处理尚需完整实装。
